# Christopher Valeriano

Information Engineering student at HAW Hamburg, based in Hamburg, Germany.

I build software with a focus on applied AI, API integration and security. My projects include Entity AI, a brand-visibility platform, and BEEMO, an AI concierge for hotels. I am interested in working student opportunities where I can turn a practical problem into software, understand its failure cases and improve it through feedback.
